# Advanced Chatbot by Sampath Magapu

An **advanced web-based chatbot system** with a user-friendly interface and smart conversational capabilities, built using HTML, CSS, JavaScript, PHP, and integrated with Botpress.

### 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP (with XAMPP server)  
- **Chatbot Engine:** [Botpress](https://botpress.com) (ready-made chatbot)  

### 🚀 Features
- Interactive web chat interface
- Real-time conversation handling
- Simple PHP backend to manage requests
- Easy integration with Botpress chatbot flows
- Local development with XAMPP for easy testing

### 📂 Installation & Setup

1. **Clone this repository:**
   ```bash
   git clone https://github.com/your-username/Advanced-chatbot_by-sampathmagapu.git
   ```

2. **Setup XAMPP:**
   - Download and install XAMPP from [Apache Friends](https://www.apachefriends.org/).
   - Place the project folder inside the `htdocs` directory.

3. **Run the XAMPP server:**
   - Open XAMPP Control Panel.
   - Start the **Apache** server.

4. **Access the project:**
   - Open your browser and go to:  
     `http://localhost/Advanced-chatbot_by-sampathmagapu/`

5. **Configure Botpress chatbot:**
   - Download and install [Botpress](https://botpress.com/docs/).
   - Create your chatbot flow.
   - Integrate the Botpress chatbot in your project following their setup guide.

### 💡 Usage
- Start chatting with your bot through the web interface.
- Customize your chatbot flow in Botpress to suit your needs.
